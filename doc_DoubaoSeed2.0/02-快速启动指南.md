# Spring JPetStore 快速启动指南

## 一、环境准备

### 1.1 必需软件
- **JDK 17** - Java 开发工具包
- **Maven 3.x** - 项目构建工具
- **IDE** - IntelliJ IDEA 或 Eclipse（可选）

### 1.2 检查环境
```bash
# 检查 Java 版本
java -version

# 检查 Maven 版本
mvn -version
```

## 二、项目启动步骤

### 2.1 方式一：Maven 命令启动（推荐）

**步骤 1：进入项目目录**
```bash
cd d:\Project\Java\spring-jpetstore
```

**步骤 2：下载依赖（首次运行）**
```bash
mvn clean compile
```

**步骤 3：启动应用**
```bash
mvn tomcat7:run
```

**步骤 4：等待启动完成**
看到如下日志说明启动成功：
```
INFO: Starting ProtocolHandler ["http-bio-8088"]
```

### 2.2 方式二：IDE 启动

**IntelliJ IDEA：**
1. 打开项目（File -> Open）
2. 等待 Maven 依赖下载完成
3. 找到 `pom.xml` 右键 -> Add as Maven Project
4. 点击右侧 Maven 面板
5. 展开 Plugins -> tomcat7
6. 双击 `tomcat7:run`

**Eclipse：**
1. Import -> Existing Maven Projects
2. 右键项目 -> Run As -> Maven build...
3. Goals 输入：`tomcat7:run`
4. 点击 Run

## 四、常见问题

### 4.1 端口被占用

**错误信息**：`Address already in use: bind`

**解决方法**：
- 方式一：修改 `pom.xml` 中的端口号
  ```xml
  <port>8089</port>  <!-- 改为其他端口 -->
  ```
- 方式二：杀掉占用 8088 端口的进程

### 4.2 Maven 依赖下载慢

**现象**：首次运行时依赖下载很慢

**解决**：项目已配置阿里云镜像，耐心等待即可

### 4.3 登录失败

**检查项**：
1. 确认用户名密码输入正确
2. 查看终端日志
3. 检查 Spring Security 配置

### 4.4 页面样式或图片不显示

**解决**：
1. 确认 `src/main/webapp` 下有 `css` 和 `images` 文件夹
2. 如果没有，手动复制到该目录
3. 重启应用

## 六、开发调试

### 6.1 修改代码后重新启动
1. 终端按 `Ctrl + C` 停止
2. 修改代码
3. 重新运行 `mvn tomcat7:run`

### 6.2 查看日志
- 应用日志：终端直接显示
- 错误日志：`我的错误/log.txt`

### 6.3 数据库修改
由于使用 H2 内存数据库，修改数据库需要：
1. 编辑 `src/main/resources/database/H2-dataload.sql`
2. 重启应用
